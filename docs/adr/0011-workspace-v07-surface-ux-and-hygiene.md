# ADR-0011: v0.3 Surface UX, readability, and hygiene decisions

- **Status:** Accepted
- **Date:** 2026-08-16
- **Context:** Wayfinder map [#79](https://github.com/kaiqiangh/dsh-workshpace-plugin/issues/79) — full-codebase review findings plus the user-reported pain points (Git Changes board hard to use; three sub-tabs' UI/UX below standard).

## Decision

1. **Diff readability** — render unified diffs with line-level coloring (green add / red remove), hunk headers, line numbers, and per-file `+N −M` stats using a pure `parseUnifiedDiff()` parser. No syntax-highlighting dependency; the parser is unit-tested and bounded.
2. **Untracked files** — show a friendly "stage it to see a diff" notice instead of an empty "No diff content". The board stays read-only; untracked file contents are never read.
3. **Liveness** — all three surfaces share a 5s refresh cadence with a manual Refresh control; the previous Changes behavior (load once on mount) was a correctness/UX defect.
4. **Shared surface primitives** — one module (`workspace-primitives.ts`) for notice/empty-state/header/chip/count/toolbar atoms and one remote-error helper set (`workspace-remote.ts`), replacing three duplicated unwrappers. Error copy is friendly, never raw `CODE: message`.
5. **Fail-open lists** — a single malformed artifact is skipped with a warning count rather than failing the whole list.
6. **Artifact carrier keyed by session + cwd** — `WorkspaceService.carrier()` uses `agentId + cwd`, so a session whose cwd moves to another workspace gets a fresh artifact carrier instead of stale artifacts from the old root. Memory keeps its existing fail-closed contract: a session rebound to a different Workspace Root still rejects with `PROJECT_UNAVAILABLE` (session identity is bound to its workspace root; see `scripts/dsh-compat-smoke.mjs`).
7. **Stat-only polling** — `WorkspaceArtifactCarrier` caches preview descriptors keyed by path + size + mtime; polls only `stat()`, previews are re-read on change or on demand.
8. **Tooling hygiene** — the `check` script globs `src/**/*.ts` (no hand-maintained list). Committed `lib/` build artifacts remain the release contract and are regenerated by `npm run build`.
9. **Documentation** — README is the delivered-reality surface; CHANGELOG records history; this ADR records the v0.7 decisions; the 2026-08-16 review doc is marked superseded; package version bumped to 0.3.0.

## Consequences

- Surface behavior and copy are now consistent across Artifacts / Memory / Changes.
- Diff rendering cost is proportional to the diff text already fetched (bounded at 512 KiB by the Host).
- Cache key changes mean a session that changes directories starts fresh state for that directory; memory stores for the old directory remain on disk and are reachable again if the session returns.
- Future surface work should extend the shared primitives rather than add per-surface UI atoms.
